# Monday Report

## The shape

```
WHAT DIED
[Assets retired this week, with the ARG_ID and why. This section is first,
always, even when it is empty. Especially when it is empty.]

WHAT WON
[Argument level, never asset level. Include spend, so a "winner" that was
simply funded harder is visible as one.]

WHAT SHIPPED
[Count by ARG_ID. Not a gallery.]

DISTINCT ARGUMENTS LIVE
[The one number from the argument census.]

NEXT THREE
[The three concepts going into production, each named to its ARG_ID and the
reason it beat the alternatives.]
```

## Rules

- Bad news first. A report that opens with wins gets read as marketing.
- Argument level, never asset level.
- No deck. One page. If it needs a meeting to be understood, it is written
  wrong.
- If nothing died this week, say so explicitly. A week where nothing was killed
  is usually a week where nothing was decided.

## Why it is Monday

So the week's production is briefed off it rather than off whatever was already
in the queue.

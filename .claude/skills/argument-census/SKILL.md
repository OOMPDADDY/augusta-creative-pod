# Argument Census

## The output

One number.

## The prompt

```
Below is every asset live right now, with descriptions.

ASSETS: [PASTE]

Group them by the ARGUMENT they make. Two assets with different visuals making
the same claim are ONE argument. Be strict: marketers see difference where
buyers see repetition.

Emit ONLY:
- a list of the distinct arguments, with asset counts
- one final line: "Distinct arguments live: N"

No commentary.
```

## Why it is one number

Because a number can be said out loud in a planning meeting and a table cannot.
Nearly every account believes it is testing six or seven arguments. The census
is the thing that settles it in one line.

## What to do with it

If N is under four, stop making assets and go back to the angle architect. More
volume against three arguments produces more coverage of three arguments.
